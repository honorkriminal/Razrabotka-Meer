# Расходы в поездке

Программа считает общую и среднюю трату по десяти записям.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python trip.py
```

В Windows PowerShell окружение активируется командой `.\.venv\Scripts\Activate.ps1`.

```text
ОТЧЁТ ПО ПОЕЗДКЕ
--------------------------------
записей: 10
всего потрачено: 7900 ₽
средняя трата: 790.00 ₽
```
