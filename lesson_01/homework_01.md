## 1

GitHub. Предполагаемый порядок обработки запросов.

| Действие | Что уходит | Что проверяет сервер | Что сохраняет | Что возвращает |
|---|---|---|---|---|
| Открыть README | Владелец, репозиторий, ветка и путь | Доступ на чтение и наличие файла | Читает содержимое из Git | Текст README |
| Отправить коммит через git push | Новые объекты Git и ссылка на ветку | Право записи и допустимость обновления ветки | Объекты и новую вершину ветки | Подтверждение обновления или причину отказа |
| Создать задачу | Название, описание и данные авторизации | Доступ, обязательное название и включены ли Issues | Задачу с номером и автором | Номер и страницу задачи |
